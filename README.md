# ساب وایرگارد و آمین‌زیا برای کورفورج

هر کانفیگ، چه متن ini باشد چه فایل conf چه لینک آماده، به یک خط `wireguard://` تبدیل می‌شود.

ساب خودش لینک‌هاست. آدرس فایل داخلش نیست.

کورفورج این را اضافه کند:

```
https://raw.githubusercontent.com/o6ash/wg-sub/main/subscription_base64.txt
```

اگر گفت بیس۶۴ را نخواند، این نسخهٔ ساده را بگذارد:

```
https://raw.githubusercontent.com/o6ash/wg-sub/main/subscription.txt
```

منبع فعلی کانال عمومی ConfigWireguard است. لینک‌ها مال همان کانال‌اند، نه سرور خودمان. تازه‌سازی از همین ماشین انجام می‌شود، چون خواندن فایل‌های کانال سشن تلگرام می‌خواهد و آن سشن داخل ریپو نیست.
